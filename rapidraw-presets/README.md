# RapidRAW 预设 / Presets

本目录包含适用于 **RapidRAW** 开源图像处理软件的预设包文件。

## 文件列表 / Files

* **[all_presets.rrpreset](./all_presets.rrpreset)**：包含了所有通用预设，包含以下风格：
  * **特色调色系列**：
    * `日系小清新`：通透清爽的冷色调，适度提升阴影与高光阶调
    * `人文浓郁对比`：高清晰度、沉稳暗部与暖色色彩分调
    * `人文室内`：针对弱光/室内场景优化的自然暖调
    * `Summer Days`：温暖胶片暖阳风，带自然胶片颗粒感
  * **Community 社区精选分组**：
    * `Cinematic` (电影青橙色调)
    * `Vintage Film` (复古低饱和胶片)
    * `Urban Teal & Orange` (都市高对比青橙)
    * `Moody Forest` (暗调森林绿)
    * `Film Inspired P400UC _rev2` (Kodak Portra 400UC 胶片风)
    * `Hyper exposed` (高调张力)
    * `AVOR - Dynamic Velvia` (Velvia 高动态鲜艳)
    * `ARP Fizz` (复古颗粒暖色)

## 使用方法 / How to Use

1. 在 **RapidRAW** 中打开预设管理界面。
2. 点击 **[导入预设 / Import]**。
3. 选择此目录下的 `all_presets.rrpreset` 文件完成导入。
