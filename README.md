# 索尼相机图像参数与 RapidRAW 预设集合

[English](./README_en.md)

---

本项目收集并存储适用于索尼相机及 RAW 格式照片的自定义图像处理参数配置文件：
* **Sony Imaging Edge Desktop (Edit)** 的 `.xml` 预设文件
* **RapidRAW** 跨平台 RAW 图像编辑软件的 `.rrpreset` 预设包文件

---

### 仓库预设列表

#### 1. Sony Imaging Edge Desktop 预设 (`.xml`)
*   [spring.xml](./spring.xml)：生机盎然、色彩明快的春日氛围感色调。微调了绿色通道，提升了饱和度并做柔和微调，展现春天的生机。
*   [summer.xml](./summer.xml)：温暖、明亮的夏季氛围感色调。调高了清晰度与饱和度，并对色温和色调曲线进行了精细微调，非常适合用于展现阳光充沛、色彩鲜艳的夏日照片。
*   [autumn.xml](./autumn.xml)：温暖、金黄、高对比的秋日氛围感色调。提升了红黄色调的饱和度，微调了红蓝色曲线，适合展现秋天树叶金黄的复古格调。
*   [winter.xml](./winter.xml)：寒冷、干净、高清晰度的冬日冷调风格。降低了整体饱和度，适当加入了冷蓝色调和高光微调，适合呈现冬日白雪皑皑、纯净宁静的画面。
*   [fl2.xml](./fl2.xml)：**FL2 模拟预设（适合 A7C2 等旧机型）**。基于原生的 FL 外观，通过提高对比度、降低饱和度、压深阴影并做红蓝冷暖分调曲线，在不支持 FL2 创意外观的旧机型上模拟出 A7M5 般厚重、怀旧的电影感胶片质感。

#### 2. RapidRAW 预设包 ([all_presets.rrpreset](./rapidraw-presets/all_presets.rrpreset))
适用于 **RapidRAW** 软件，包含多种精调风格与社区优秀预设：

*   **独创 / 特色预设：**
    *   **Sony FL 胶片 (Film Look)**：模拟索尼 FL 创意外观。高对比度、降低饱和度、压深阴影，并结合红蓝 Tone 曲线与青蓝/暖调色彩分调，呈现厚重怀旧的电影感胶片质感。
    *   **日系小清新**：清透、明亮的冷调风格。提升暗部与曝光，压低高光，阴影注入青蓝色调，呈现通透自然的人像与风景质感。
    *   **人文浓郁对比**：高清晰度与高对比度的人文纪实风格。暗部沉稳，高光与中调带暖色分调，凸显画面立体感与故事感。
    *   **人文室内**：专为弱光/室内人文场景优化。适度提亮阴影与曝光，保持自然的室内暖色调与清晰细节。
    *   **Summer Days**：浓郁阳光感与夏日胶片风。暖色温、强色彩分调与适度胶片颗粒感，打造暖洋洋的夏日氛围。
*   **Community 社区色彩分组：**
    *   **Cinematic**：经典电影质感，青蓝阴影与暖中调分调，压低高光并保持丰富阶调。
    *   **Vintage Film**：复古胶片风格，低对比度、降低饱和度并带有胶片颗粒感。
    *   **Urban Teal & Orange**：经典青橙都市风格，高对比度与强烈冷暖对比。
    *   **Moody Forest**：郁郁葱葱的暗调森林风，降饱和、阴影冷蓝、高光偏黄绿。
    *   **Film Inspired P400UC _rev2**：借鉴 Kodak Portra 400UC 胶片质感，高曝光、柔和高光与自然颗粒感。
    *   **Hyper exposed**：高调过曝感与高对比度色调，中音区偏暖，富有视觉张力。
    *   **AVOR - Dynamic Velvia**：模拟经典 Velvia 胶片的丰富色彩与高动态响应，增强阴影/高光层次。
    *   **ARP Fizz**：带有轻微颗粒感的淡雅复古色调，高光与中调偏暖。

### 使用说明

#### 📷 Sony Imaging Edge Desktop (`.xml`) 使用方法

##### 1. 单张图片载入预设
在 **Edit** 软件窗口中，将预设应用到当前正在编辑的照片：
1. 在 Imaging Edge Desktop 的 **Edit** 窗口中打开需要编辑的 RAW 格式照片（`.ARW`）。
2. 从顶部菜单栏选择 **[编辑]** -> **[图像处理设置]** -> **[载入并应用设置...]**。
3. 选择所需的预设文件（例如 [summer.xml](./summer.xml)）并点击 **[打开]**，参数将立即应用到当前照片上。

##### 2. 批量应用预设（导出时）
在导出时一次性将预设应用到多张照片：
1. 在 **Viewer** 窗口中，选中所有需要处理的照片。
2. 点击工具栏的 **[输出]**（或 **[导出]**）图标，或从菜单中选择 **[文件]** -> **[输出...]**。
3. 在弹出的输出设置窗口中，勾选 **[应用选定的图像处理设置到每个 RAW 文件]**。
4. 点击设置栏旁边的 **[浏览...]**，选择已保存的 `.xml` 预设文件，然后点击 **[继续]** 即可开始批量输出。

##### 3. 快速复制与粘贴设置
如果只是想在两张照片间快速迁移调整参数，无需保存文件：
*   **复制：** 在 **Edit** 窗口显示已调整好的图像，选择 **[编辑]** -> **[图像处理设置]** -> **[复制]**（或使用快捷键 `Cmd + C` / `Ctrl + C`）。
*   **粘贴：** 切换到目标图片，选择 **[编辑]** -> **[图像处理设置]** -> **[粘贴]**（或使用快捷键 `Cmd + V` / `Ctrl + V`）。

##### 4. 导出保存您自己的预设
当您调整好一张照片，希望将当前参数保存为文件：
*   在 **Edit** 窗口工具栏的 **[保存]**（磁盘）图标旁点击下拉箭头，选择 **[保存图像处理设置]**。
*   或者在顶部菜单中选择 **[编辑]** -> **[图像处理设置]** -> **[保存...]**，指定存储位置和文件名即可。

---

#### 🚀 RapidRAW (`.rrpreset`) 使用方法

1. 打开 **RapidRAW** 图像处理软件。
2. 进入预设 (Presets) 管理面板。
3. 点击 **[导入预设 / Import]** 按钮。
4. 选择本项目中的 [all_presets.rrpreset](./rapidraw-presets/all_presets.rrpreset) 文件。
5. 导入成功后，即可在预设列表中实时预览并一键应用各项预设风格。
